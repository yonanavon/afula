# מדריך העסקים של עפולה

אתר סטטי שמציג את רשימת עסקי המזון בכשרות מהודרת בעפולה, עפולה עילית וגבעת המורה.
הנתונים מנוהלים בגיליון Google Sheets שהמשגיח עורך, והאתר מתעדכן מאליו.

---

## איך זה עובד

```
  גיליון Google Sheets  ──┬──►  הדפדפן שולף ישירות בכל טעינה   (עדכון מיידי)
   (המשגיח עורך)          │
                          └──►  GitHub Actions מסנכרן כל שעה ל-data/*.json
                                       │
                                       └──►  גיבוי, אם הגיליון אינו זמין
```

הדפדפן מנסה תמיד קודם את הגיליון החי, כך שעריכה של המשגיח מופיעה באתר בטעינה הבאה.
אם הגיליון איטי, חסום או לא זמין — האתר נופל לעותק המסונכרן שבתיקיית `data/`
ולא נשאר ריק.

---

## הקמה — פעם אחת

### 1. יצירת הגיליון

1. צרו גיליון חדש ב-[Google Sheets](https://sheets.new).
2. צרו בו שתי לשוניות בשמות המדויקים: **`עסקים`** ו-**`הגדרות`**.
3. ייבאו לכל לשונית את קובץ ה-CSV המתאים מתיקיית `sheet-template/`:
   קובץ ← ייבוא ← העלאה ← בחרו את הקובץ ← "החלפת הגיליון הנוכחי" ← ייבוא.
4. שיתוף ← גישה כללית ← **"כל מי שיש לו הקישור"** ← הרשאת **מציג**.
   בלי זה האתר לא יוכל לקרוא את הנתונים.

### 2. חיבור האתר לגיליון

העתיקו את מזהה הגיליון מתוך הכתובת שלו:

```
https://docs.google.com/spreadsheets/d/(((המזהה נמצא כאן)))/edit
```

והדביקו אותו ב-`assets/js/config.js`:

```js
export const CONFIG = {
  sheetId: 'הדביקו כאן את המזהה',
  ...
};
```

### 3. הפעלת הסנכרון האוטומטי (הגיבוי)

ב-GitHub, בתוך הריפוזיטורי:
**Settings ← Secrets and variables ← Actions ← לשונית Variables ← New repository variable**

| Name | Value |
|---|---|
| `SHEET_ID` | מזהה הגיליון (אותו ערך מסעיף 2) |

מכאן ה-workflow שב-`.github/workflows/sync-data.yml` ירוץ כל שעה.
אפשר גם להריץ אותו ידנית מלשונית **Actions**.

### 4. תאריך העדכון האוטומטי

בגיליון: **תוספים ← Apps Script**, הדביקו את התוכן של `sheet-template/Code.gs`,
ועקבו אחרי הוראות ההתקנה שבראש הקובץ (הוספת טריגר `On edit`).

מרגע זה, כל עריכה בלשונית `עסקים` מעדכנת אוטומטית את השדה **"תאריך עדכון"**
בלשונית `הגדרות`, והאתר מציג אותו בכותרת ובתחתית הדף.

### 5. פרסום האתר

**Settings ← Pages ← Source: Deploy from a branch**, ובחרו את הענף ואת התיקייה `/ (root)`.

## עריכה שוטפת — מה שהמשגיח צריך לדעת

כל השינויים נעשים בגיליון בלבד. אין צורך לגעת בקוד.

### לשונית `עסקים`

כל שורה היא עסק אחד. סדר השורות הוא סדר התצוגה באתר.

| עמודה | מה כותבים | חובה |
|---|---|:---:|
| **שם העסק** | שם מלא כפי שיוצג בכותרת הכרטיס | ✔ |
| **סוג עסק** | פיצרייה, מאפייה, פלאפל, מסעדה, מרכול, מזנון מהיר… | |
| **קטגוריה** | `חלבי` / `בשרי` / `פרווה`. אפשר כמה, מופרדים בפסיק | |
| **כתובת** | רחוב ומספר, בלי שם העיר | |
| **אזור** | עפולה / עפולה עילית / גבעת המורה — משמש לסינון | |
| **טלפון** | מספר ראשי. הופך לכפתור חיוג | |
| **טלפון נוסף** | מספר שני, למשל להזמנת משלוחים | |
| **קישור מפות** | רק אם רוצים לעקוף את קישור הניווט האוטומטי | |
| **השגחה נוספת** | השגחה על **העסק עצמו**, מעבר לרבנות עפולה | |
| **המוצרים בכשרויות** | הכשרות של **חומרי הגלם והמוצרים** שבהם העסק משתמש | |
| **הערות** | סייגים, מוצרים חריגים, הסברים | |
| **קישור לפרטי ההשגחה** | הדף של העסק ב-mdafula.org.il | |
| **קישור לתפריט** | תפריט מקוון, אתר או עמוד פייסבוק | |
| **תמונה** | כתובת של תמונת העסק. אם ריק — מוצג אייקון לפי סוג העסק | |
| **סטטוס** | `פעיל`, או `לא פעיל` לעסק שאינו פועל כרגע | |

> **שימו לב להבדל בין שתי עמודות ההשגחה:**
> **"השגחה נוספת"** = מי משגיח על העסק עצמו, בנוסף לרבנות עפולה.
> **"המוצרים בכשרויות"** = באיזו כשרות המוצרים וחומרי הגלם שהעסק קונה ומשתמש בהם.
> יש עסקים שיש להם את שתיהן, וכל אחת מוצגת בשורה נפרדת ובאייקון משלה.

**עסק שסגר או אינו פעיל** — אין צורך למחוק את השורה. כתבו `לא פעיל` בעמודת הסטטוס.
העסק ייעלם מהתצוגה הרגילה, ויופיע רק למי שיסמן "הצגת עסקים שאינם פעילים".

**הוספת עסק** — פשוט מוסיפים שורה חדשה. אין צורך למספר.

### לשונית `הגדרות`

מבנה של שתי עמודות: שם ההגדרה מימין, הערך משמאל.

| הגדרה | לאן זה הולך |
|---|---|
| כותרת האתר | הכותרת הראשית ושם הכרטיסייה בדפדפן |
| כותרת משנה | שורת ההסבר מתחת לכותרת |
| תאריך עדכון | מתעדכן אוטומטית (סעיף 4). מוצג בכותרת ובתחתית |
| תאריך עברי | מוצג לצד התאריך הלועזי בכותרת |
| טקסט הקדמה | הטקסט שבתוך "על הרשימה ותוקף ההמלצה" |
| טקסט סיום | שורת הברכה בתחתית הדף |
| קישור להפצה | הקישור שמאחורי "שיתוף הרשימה" |

**אל תשנו את השמות שבעמודה הימנית** — האתר מזהה לפיהם. את הערכים שמשמאל אפשר לשנות בחופשיות.

## מבנה הפרויקט

```
index.html                     מבנה הדף
assets/css/styles.css          עיצוב, כולל מצב כהה
assets/js/config.js            מזהה הגיליון והגדרות טכניות
assets/js/schema.js            מיפוי עמודות הגיליון ← שדות הקוד
assets/js/sheet.js             שליפת הגיליון ופענוח CSV
assets/js/app.js               סינון, חיפוש ורינדור הכרטיסים
data/*.json                    גיבוי מסונכרן מהגיליון
scripts/sync.mjs               מושך את הגיליון אל data/
scripts/make-sheet-template.mjs  מייצר את קובצי ה-CSV מתוך data/
sheet-template/                CSV לייבוא + הסקריפט לתאריך העדכון
```

**הוספת עמודה חדשה** מתבצעת במקום אחד: `assets/js/schema.js`.
הוסיפו שם את כותרת העמודה ואת שם השדה, והוסיפו את העמודה בגיליון באותו שם בדיוק.

## הרצה מקומית

```bash
python3 -m http.server 8000     # ואז פתחו http://localhost:8000
node scripts/sync.mjs           # משיכה ידנית מהגיליון (דורש SHEET_ID)
```
